# Experiments

This folder holds one subfolder per open-source project studied. Each project runs the same four pipeline configurations (C1–C4), instrumented as workflow files in this repository's own `.github/workflows/` (no forking — every project is checked out externally at a fixed tag). Measurement outputs are stored here, one subfolder per project.

## The Four Configurations

Defined once per project as workflow files named `p{NN}-{project}-c{1-4}-{type}.yml`, all living in this repository's root `.github/workflows/`.

| Config | What changes | Strategy |
|---|---|---|
| **C1** | Nothing — Eco-CI added for measurement only | Baseline |
| **C2** | Dependency caching enabled (idiomatic per ecosystem: `cache: pip` / `npm` cache action / `cache: gradle` / `cache: maven` / `cache: true` on setup-go) | Caching only |
| **C3** | Separate workflow files merged into one, where the project has more than one to merge | Consolidation only |
| **C4** | C3's structure + caching + path-based trigger filters | All three combined |

For every project except HTTPie, the upstream CI is already a single self-contained job, so C1 and C3 are structurally identical (Section 3.2.5) — this is stated explicitly in each project's README, not discovered as a surprise in the results.

## Adding a New Project

1. Research the project's own CI (test command, dependency manager, existing workflow structure) via the GitHub API.
2. Create four workflow files at the repo root: `.github/workflows/p{NN}-{project}-c{1-4}-*.yml`, following the pattern in an existing project (external checkout at a fixed tag, identical Eco-CI instrumentation, no modification to the subject code).
3. Commit, push, and trigger one validation run per configuration before committing to the full protocol (Appendix B).
4. Create `experiments/project-{NN}-{name}/README.md` and `results/` here, matching the structure below.

## Folder Structure per Project

```
project-NN-name/
├── README.md                 # project summary, configuration table, status
├── results/
│   ├── raw_data.csv          # Eco-CI measurements, populated by collect_results.py
│   └── figures/               # charts generated by the analysis notebook
└── RESEARCH_LOG.md            # audit notes, bugs found and fixed (project 01 only so far)
```

Shared scripts (`trigger_runs.py`, `collect_results.py`, `run_experiment.sh`) live in `project-01-httpie-cli/scripts/` and take `--workflow <filename>` to target any project's workflow file.
